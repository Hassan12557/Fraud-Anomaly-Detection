
# Exploratory Data Analysis Questions

## Business Objective

Understand transaction behavior and identify
patterns that may help an unsupervised model
prioritize suspicious transactions.

## Research Questions

1. What is the fraud percentage?
2. How do transaction amounts differ by class?
3. How does transaction activity vary over time?
4. Which PCA features show distributional differences?
5. Which variables have strong correlations?
6. What is the impact of duplicate records?
7. Which findings can inform anomaly detection?

## Important Restriction

The Class column is used only for exploratory
analysis and evaluation.

It must not be included in unsupervised
model training.
